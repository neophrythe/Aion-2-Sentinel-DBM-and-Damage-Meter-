# Security reporting

Please use GitHub's private vulnerability reporting for security-sensitive findings. For ordinary startup, OCR or meter problems, use the public bug-report form.

Report the affected version, impact and a minimal reproduction. Do not publish account credentials, private signing material or unredacted capture files. The maintainer is [neophrythe](https://github.com/neophrythe).

Version 0.6.6 is an Unfinished Beta. Signed critical-file manifests verify protected file integrity; they are not Windows Authenticode publisher signing or a security boundary against a local attacker who modifies the verifier. Archive CRC and SHA-256 checks verify transport integrity separately.
