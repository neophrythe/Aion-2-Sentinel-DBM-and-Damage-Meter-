## Compact listing

AION Sentinel combines movable boss warnings with an optional DPS meter for the AION 2 EU / International English client. Start with three controls: Combat HUD, Start / Stop observation and Damage meter. Standard target names, levels, location headings and compatible profiles are selected automatically. Live meter capture requires Npcap. **Untested 0.6.6 preview; boss mechanics and current-game accuracy remain incomplete.**

## Community announcement

**AION Sentinel 0.6.6 — Untested Preview**

Boss warnings + damage meter, with a simpler three-control window and automatic target/location recognition. Move action warnings and timer groups independently. Enable the meter only when wanted; it discovers its network adapter automatically and needs a separately installed Npcap driver.

The catalog has 1,002 profiles, but only 223 have some warning support. The others identify encounters without supplying mechanics. No new functional or live-game tests were run for this preview.
