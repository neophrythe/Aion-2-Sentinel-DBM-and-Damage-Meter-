# AION Sentinel 0.6.10 — FAQ

Created by **Neophrythe & Dr.Tatsu**.

**Unfinished Beta. Active development — gameplay validation pending.**

## What does the new countdown measure?

The estimated end of a currently observed target cast. Fresh explicit remaining seconds or supported changing cast progress can sustain it. A skill name alone does not start a clock; missing, hidden or ambiguous evidence can leave it absent. It does not time individual waves, jump moments or recurring fight sequences. See [cast timing](https://github.com/neophrythe/Aion-2-Sentinel-DBM-and-Damage-Meter-/blob/main/docs/CAST_TIMING.md).

## Are all bosses covered?

The catalog has 1,002 profile identities; warning coverage remains partial. The timing reference contains 550 accepted skill IDs across 209 profiles; those are source-metadata counts, not verified live cast bars or complete fights.

## Do I need to configure a timer?

Automatic target-cast estimates need no new beginner control. Use automatic HUD discovery, keep readable English target and minimap headings visible, start observation and bring the game to the foreground. Expert Cast-end heads-up defaults to 3 seconds and accepts 0–30 seconds. Manual-region mode does not supply automatic target-cast timing.

## Is Npcap included?

It is installed separately. Existing Npcap skips guided setup. If absent, the optional meter offers a user-consented official Npcap 1.89 download, pinned SHA-256 and publisher-signature checks, then the visible installer and Windows elevation prompt. The user reviews the license and selects installation options. Cancellation or failure keeps capture off while OCR remains available. A required reboot does not restart Windows automatically.

## What has been verified?

Compilation, file signatures and archive integrity have been checked. Gameplay validation is pending; those structural checks do not establish application behavior or cast-end accuracy. Current EU damage accuracy remains unverified.
