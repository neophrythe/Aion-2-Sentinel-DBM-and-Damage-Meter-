For a confirmed target and uniquely associated English skill cue, repeated independent measurements of explicit remaining seconds or a changing cast bar can supply a HUD countdown marked **cast (est.)**. Expert Cues offers a separate **Cast-end heads-up**, defaulting to 3 seconds and adjustable from 0 to 30 seconds; zero disables that heads-up. Missing, hidden or ambiguous cast evidence can leave the countdown absent. Frozen frames do not sustain it.

The reviewed static timing reference links **550 skill IDs to 209 profiles**. These are source-inventory counts, not verified live cast bars or complete fight timelines. Raw `CastingTime` and `NeedCoolTime` units remain unverified; cooldown supplies no repeat interval. Range-warning metadata supplies no wave-impact clock. Individual wave sequences, recurring boss schedules and cast-end accuracy remain to be established in gameplay.

The catalog remains **1,002 profiles: 223 with some warning support and 779 identity-only**. Gameplay validation is pending; source compilation and package integrity have been checked. Boss-mechanic coverage remains partial.
