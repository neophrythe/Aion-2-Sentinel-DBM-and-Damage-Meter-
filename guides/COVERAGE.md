# Coverage and validation — 0.6.6

All figures describe the reviewed English Steam/reference data. They are not counts of live-verified fights.

| Category | Profiles | Some warning support | Identity-only |
| --- | ---: | ---: | ---: |
| Whole inventory | 1,002 | 223 | 779 |
| World bosses | 51 | 26 | 25 |
| High-GS source instance profiles | 86 | 46 | 40 |
| World + high-GS targets | 137 | 72 | 65 |

The public world list has 54 entries but 51 distinct profiles because three names occur in more than one region. Its 56 NPC templates are retained. High-GS scope includes 83 source instance-map variants whose explicit entrance requirement is at least 1,400. Six public Explore/Conquest variants explicitly supply qualifying GS. Internal Easy/Normal/Hard variants are not translated into those modes; no player's gear is measured.

The existing reference supplies 859 grouped exact English skill rules, 54 public HP hints and three guarded reactor hints. The new Tetrata reinforcement reference at 50% HP requires its exact NPC template and one of eight proven maps. This adds one supported profile to the whole inventory; it does not fill the 65 target-profile gaps.

Published guide material contains 35 encounter entries and 83 mechanic references. Twelve of 19 eligible published skill candidates have local ownership joins, yielding 23 response-rule associations across 17 profiles. These are structural joins, not successful live observations. Conflicting HP estimates, historical Ludra and Asian reference responses remain inactive in current Global warning rules.

Generated warnings require actual visible complete-line cues, confirmed twice. Static skill lists often mark text hidden; a database label cannot prove that the current client displays it. Damage-hit skill IDs are not a verified cast-start source. No second-based boss timeline is supplied.

When mode remains ambiguous, only identical enabled owned skill cues shared by every compatible variant can run. No variant HP hint or timer is activated from that fallback. Unknown map links and same-name normal/summon candidates remain unresolved when evidence is insufficient.

**No new unit, functional, integration, executable, OCR, UI or live tests were run for 0.6.6.** Compilation, signed-file verification, archive CRC and extracted-file SHA matching were structural checks only. Earlier versions' validation results are not reused as proof of this build.
