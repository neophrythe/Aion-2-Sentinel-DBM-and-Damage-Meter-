# Contributing

This is a public release/documentation repository. Use Issues to report reproducible problems, suggest improvements or provide encounter evidence.

Encounter reports are most useful with the exact English boss name, instance/mode, visible cue and a short recording or screenshot whose private information is removed. Distinguish observed facts from estimated timings. Complete identity coverage does not establish every mechanic.

Documentation corrections and promotional-material improvements are welcome. Do not submit original third-party bot files, account credentials, private captures, proprietary game dumps or unrelated implementation source to this repository.
